    导出单状态机
    draft→ building→ built→ approving（ITSM）→ approved→ deploying→ deployed
    任意态可入 failed / cancelled；v1 中 approving → approved → deploying 人工推进，v2 接 ITSM / 部署回调自动化。
    v1 完成定义（DoD）
    仅凭 4 件套在任一全新 namespace 执行一次 helm upgrade --install 部署成功：建库 hook 执行、initContainer 注入 /config、Pod Ready、/.well-known/agent-card.json 可达，全程不依赖平台 backend / 共享 PVC / platform_config。验证手段：charts-ci 增加 oaf-agent lint + template 渲染矩阵；kind 集群以样例 values 实装冒烟。
