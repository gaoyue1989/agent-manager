Agent Manager 蓝图与路线图

面向实际业务的智能体交付与持续运营平台
管理沟通稿 · 2026 年 10 月 · 基于当前仓库已实现的能力整理

一、蓝图

定位：帮助业务团队把智能体接入现有流程，并持续管理其质量、风险与成本—— 不追求自研所有模型与基础设施，也不替代业务系统。平台按四个业务结果建设：
交付更容易
新场景复用已有配置、技能与工具连接，不必从零搭建
运行更可靠
任务状态可见、异常可处理、关键操作可控、更新更稳妥
效果可衡量
能回答任务完成情况、何处需人工、版本改进是否有效
经验可复用
已验证的技能、方案与评测样本用于后续项目

① 单一 Agent 部署Deploy & Run ● 基本完成
核心问题
能否可靠地建起来、跑起来
目标
让一个智能体从配置文件变成稳定、可访问、可管理的线上服务
已具备
  • 配置包上传 / 版本管理 / 在线编辑
  • 发布 / 重新发布 / 下线 / 删除
  • 流式交互 · 断线续传 · 文件处理
  • 工具调用 · 沙箱执行 · 会话保存
  • 运行配置统一维护 · 敏感配置分离
  • 智能发布助手：对话式发布与查询
  • 平台管理与业务运行分离
  • Helm 部署 · 链路追踪与监控
待补齐
  • 平台管理后端单副本，多副本条件待明确
  • 多服务数据隔离仍靠人工配置（已知风险）
  • 生产运维：备份恢复、日志留存、异常通知
进入下一步的标志：一个业务场景可以在不接触底层配置的情况下完成部署、使用和监控。
② 多 Agent 协同Collaboration ◐ 已打通并验证
核心问题
能否让多个智能体分工配合
目标
让多个有不同职责的智能体分工配合，完成单个 Agent 做不好的任务
已具备
  • 并行子 Agent（共享上下文与权限）
  • 跨服务编排（远程子 Agent）
  • 5 Agent 订单履约示例（已验证）
  • 协作中人工确认（跨服务确认卡）
  • 按用户与会话分维度隔离
  • 多副本与会话跨节点恢复
待补齐
  • 缺统一观测入口：整条协作链路无法串起来看
  • 出错时需顺调用关系回溯根因
  • 协作能力仍依赖开发配置，缺产品化复用
进入下一步的标志：一次多 Agent 任务的完整执行过程可以被完整回看，问题能定位到具体环节。
③ 评测飞轮补齐Evaluation Loop ◐ 骨架已建
核心问题
能否测准效果、证明改进有效
目标
回答效果如何、改进有没有效、发布是否引入退化
已具备
  • 调用录制（模型 / 沙箱 / 工具 / 服务）
  • 离线回放（无需真实模型）
  • 确定性评估 + 模型评估引擎
  • 评测界面：用例管理 / 报告 / 对比
  • 飞轮自检与离线回放已接入 CI
待补齐
  • 门禁轨：尚未作为独立必需检查接入（设计已有）
  • 趋势轨：定期质量评分与告警尚未落地（设计已有）
  • 业务效果口径：尚未与任务完成率等指标对应
  • 自动化评估替代人工：评估器仍以研发验证为主
  • 评测用例与改进记录尚未沉淀为资产
进入下一步的标志：一次版本发布能明确回答“没有引入退化”；一次效果改进能拿出可对比的数据。
④ 资产沉淀与复用Asset Reuse ○ 刚起步
核心问题
能否复制到下一个场景
目标
让“做好一个场景”变成“更快做好下一批场景”
已具备
  • 配置包版本管理与派生溯源
  • L2 包内共享技能（运行中可动态改）
  • L4 用户个人技能覆盖
  • 会话内自主沉淀新技能（自学习）
  • 5 Agent 协作可作为编排模板
  • 用例库与趋势历史
待补齐
  • 缺显式资产目录：哪些配置 / 技能 / 用例可复用未说清
  • 技能含可执行脚本，上线前缺静态检查
  • 缺服务身份标识与权限记录
  • 调用量与 token 成本缺运营视图与告警
  • 复制路径：派生新场景的操作路径需固化
进入成熟的标志：新场景的大部分配置可以由已有资产组装完成；资产的调用情况与效果有数据可查。

推进优先级

1评测飞轮补齐
唯一“缺了它后面全不稳”的能力，且骨架已建、路径清晰
2单一 Agent 收尾
补齐数据隔离与运维能力，扩大部署前必须完成
3资产沉淀与复用
需前两步跑通，否则沉淀只会积累技术债
4多 Agent 产品化
复杂度最高，放在评测能力可靠之后

前期已解决智能体“如何统一交付、持续运行、追踪问题”的基础问题； 下一阶段要回答的是 “业务是否真正受益、能否稳定使用、能否低成本复制”。 每一步都是下一步的前提：没有可靠的单 Agent 运行底座就没有协同；协同的复杂度必须靠评测飞轮才能管住。

说明：文中“已具备”指仓库中已有实现或验证记录，不代表本次重新进行全量验收，也不代表已取得规模化生产运营成绩； 各阶段能力依据本仓库平台说明、配置包与技能管理文档、链路追踪与评测录制回放设计、订单履约示例及持续集成配置整理。
