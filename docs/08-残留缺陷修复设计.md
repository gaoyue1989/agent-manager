## 2. 官方方案分析

### 2.1 ToolGroup + enableMetaTool

从 AgentScope 官方文档 ([Tool](https://java.agentscope.io/v2/zh/docs/building-blocks/tool.html))：

**ToolGroup** 是带名称的 tool / MCP / skill 集合。把 group 注册到 `Toolkit` 后再用 builder 启用 meta tool：

```java
Toolkit toolkit = new Toolkit();
toolkit.registerTool(new BasicTools());

ToolGroup database = new ToolGroup(
    "database",
    "Tools for database operations.",
    ToolGroupScope.SESSION,
    /* active = */ false);
database.addTool("db_query");
database.addTool("db_migrate");
toolkit.registerTool(new DatabaseTools());
toolkit.registerToolGroup(database);

ReActAgent agent = ReActAgent.builder()
    .name("router")
    .toolkit(toolkit)
    .enableMetaTool(true)  // 启用 reset_tools meta tool
    .build();
```

**关键行为：**
- `"basic"` 组中的 tool 始终暴露，meta tool 不会影响它们
- 每次调用 `reset_tools` 都会**整体覆盖**激活集合
- 未激活 group 中的 tool 不会出现在 agent 的工具 schema 中

## 3. 修改方案

### 3.1 MCP 工具命名规范 (问题 2.6)

**问题代码：** `McpToolRegistrar.java:113-128`

```java
// 当前：裸名注册
var agentTool = new McpTool(
    tool.name(),  // ❌ 裸名，跨 server 冲突
    ...
);
```

**修复方案：**

```java
// 修复：使用官方命名规范 mcp__{server}__{tool}
var toolName = "mcp__" + serverName + "__" + tool.name();
var agentTool = new McpTool(
    toolName,
    tool.description() != null ? tool.description() : "",
    McpTool.convertMcpSchemaToParameters(
        tool.inputSchema(), Collections.emptySet()),
    tool.outputSchema() != null ? new ConcurrentHashMap<>(tool.outputSchema()) : null,
    wrapper,
    null,
    serverName,
    true // readOnly
);
toolkit.registerTool(agentTool);
registeredTools.put(serverName + ":" + tool.name(), new ToolInfo(tool.name(), tool.description(), serverName));
log.info("MCP tool '{}' registered as '{}'", tool.name(), toolName);
```

**注意：** `registeredTools` 缓存仍使用原始名（`tool.name()`），因为 `/tools` API 需要返回给用户的友好名称，而 `McpTool` 内部使用规范命名。

### 3.2 ActiveMCP 工具子集 (问题 1.5/2.1)

**问题分析：**

`McpToolRegistrar.registerReadOnly()` 遍历所有工具并注册，没有根据 ActiveMCP.json 过滤。

**修复方案：** 在 `McpToolRegistrar` 中添加 ActiveMCP.json 过滤

```java
// 新增：加载 ActiveMCP.json 配置
private Map<String, Boolean> loadActiveMcpConfig(OafConfig.McpServerConfig mcp) {
    var mcpDir = configDir.resolve(
        mcp.configDir() == null || mcp.configDir().isEmpty() ? mcp.server() : mcp.configDir());
    if (!mcpDir.toFile().exists()) {
        mcpDir = configDir.resolve(mcp.server());
    }
    var activeMcp = mcpDir.resolve("ActiveMCP.json");
    if (!activeMcp.toFile().exists()) {
        return null;  // 无配置，不限制
    }
    try {
        var node = mapper.readTree(activeMcp.toFile());
        var result = new LinkedHashMap<String, Boolean>();
        if (node.has("selectedTools")) {
            for (var toolNode : node.get("selectedTools")) {
                var name = toolNode.get("name").asText();
                var enabled = !toolNode.has("enabled") || toolNode.get("enabled").asBoolean(true);
                result.put(name, enabled);
            }
        }
        return result;
    } catch (Exception e) {
        log.warn("Failed to load ActiveMCP.json for {}: {}", mcp.server(), e.getMessage());
        return null;
    }
}

// 修改 registerReadOnly：根据 ActiveMCP.json 过滤工具
private void registerReadOnly(Toolkit toolkit, McpClientWrapper wrapper, String serverName,
                              Map<String, Boolean> activeMcpConfig) {
    wrapper.initialize().block();
    var tools = wrapper.listTools().block();
    if (tools == null) {
        log.warn("MCP {} listTools returned null", serverName);
        return;
    }
    for (var tool : tools) {
        // ActiveMCP 过滤：enabled=false 的工具不注册
        if (activeMcpConfig != null) {
            if (activeMcpConfig.containsKey(tool.name()) && !activeMcpConfig.get(tool.name())) {
                log.info("MCP tool '{}' skipped (ActiveMCP enabled=false)", tool.name());
                continue;
            }
        }
        // 使用官方命名规范注册
        var toolName = "mcp__" + serverName + "__" + tool.name();
        var agentTool = new McpTool(
            toolName,
            tool.description() != null ? tool.description() : "",
            McpTool.convertMcpSchemaToParameters(tool.inputSchema(), Collections.emptySet()),
            tool.outputSchema() != null ? new ConcurrentHashMap<>(tool.outputSchema()) : null,
            wrapper,
            null,
            serverName,
            true
        );
        toolkit.registerTool(agentTool);
        registeredTools.put(serverName + ":" + tool.name(), new ToolInfo(tool.name(), tool.description(), serverName));
        log.info("MCP tool '{}' registered as '{}'", tool.name(), toolName);
    }
}
```

### 3.3 `/mcp` tool_count 真实注册数 (问题 2.1)

**修复方案：** `McpManager` 注入 `McpToolRegistrar`，使用注册缓存

```java
@Service
public class McpManager {
    private final Path mcpConfigsDir;
    private final ObjectMapper mapper = new ObjectMapper();
    private final McpToolRegistrar mcpToolRegistrar;

    public McpManager(java.nio.file.Path configDir, McpToolRegistrar mcpToolRegistrar) {
        this.mcpConfigsDir = configDir;
        this.mcpToolRegistrar = mcpToolRegistrar;
    }

    public List<Map<String, Object>> getMcpSummaries(List<Map<String, Object>> mcpConfigs) {
        var summaries = new ArrayList<Map<String, Object>>();
        for (var mc : mcpConfigs) {
            var serverName = (String) mc.getOrDefault("server", "unknown");
            
            // 使用 McpToolRegistrar 的注册缓存获取真实 tool_count
            int toolCount = mcpToolRegistrar.getToolsByServer(serverName).size();
            
            @SuppressWarnings("unchecked")
            var conn = (Map<String, Object>) mc.getOrDefault("connection", Map.of());
            
            summaries.add(Map.of(
                "server", serverName,
                "vendor", mc.getOrDefault("vendor", ""),
                "connection_type", conn.getOrDefault("type", "N/A"),
                "url", conn.getOrDefault("url", "N/A"),
                "tool_count", toolCount
            ));
        }
        return summaries;
    }
}
```

**修改 `AgentScopeConfig`：**

```java
@Bean
public McpManager mcpManager(AgentManagerProperties props, McpToolRegistrar mcpToolRegistrar) {
    return new McpManager(Path.of(props.configDir()), mcpToolRegistrar);
}
```

### 3.4 工具面管理机制 (问题 2.2)

**当前状态：** agent-framework 零引用 ToolGroup/enableMetaTool，所有工具进 `basic` 组始终暴露。

**评估：** 这是配置选择而非缺陷。启用 ToolGroup 是一个较大的架构变更，需要：
1. 定义 ToolGroup 分类（文件、记忆、会话、MCP 等）
2. 修改 AgentScopeConfig 创建 ToolGroup
3. 可能需要修改 HarnessAgent 构建流程

**建议：** 作为后续优化，不在本轮修复中实施。当前优先修复 P1 缺陷（3.1-3.3）。

**未来方案草图：**

```java
// 定义 ToolGroup
ToolGroup fileTools = new ToolGroup("file", "File operations", ToolGroupScope.SESSION, true);
ToolGroup memoryTools = new ToolGroup("memory", "Memory operations", ToolGroupScope.SESSION, true);

ToolGroup mcpTools = new ToolGroup("mcp", "MCP business tools", ToolGroupScope.SESSION, true);

// 注册工具到 group
toolkit.registration().tool(new FileTools()).group("file").apply();

// 启用 meta tool

    .enableMetaTool(true)  // Agent 可通过 reset_tools 管理工具组
    ...
    .build();
```

## 6. 风险评估

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| MCP 工具命名变更影响现有调用 | 中 | 内部命名变更，API 层面透明（registeredTools 缓存仍用原始名） |
| ActiveMCP 过滤影响标准注册路径 | 低 | 有配置时走手动注册，无配置时保持原有行为 |
| McpManager 注入 McpToolRegistrar 循环依赖 | 低 | McpToolRegistrar 已是 @Service Bean |
