# Example Skill 使用说明

## 何时使用
当用户请求演示标准技能目录结构或验证沙箱技能同步能力时，按本说明执行。

## 执行步骤
1. 检查当前工作区与技能目录内附带的脚本或参考文档。
2. 若需要运行脚本，通过 `execute` 工具在沙箱中执行并校验返回码。
3. 汇总执行结果并返回给用户。
